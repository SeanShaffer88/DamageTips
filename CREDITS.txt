References
  - SpellCalc by coolmodi, for mana sustain, caster stats, and the
    ideas of showing scaling and hit/crit-adjusted output:
    https://github.com/coolmodi/SpellCalc/tree/c6b53a7c07c90d7f7c261f8aa71b5a3e9d5ebd6c
    DamageTips implements these features against the Forever client APIs.
  - WoW Forever 1.60.1.70888 client tables, extracted by Wago Tools.
    SpellEffect coefficients and effect types were cross-checked against
    the ranked English descriptions, school/flags, class and spell levels.
    https://wago.tools/db2/SpellEffect/csv?build=1.60.1.70888
    https://wago.tools/db2/Spell/csv?build=1.60.1.70888
    https://wago.tools/db2/SpellName/csv?build=1.60.1.70888
    https://wago.tools/db2/SpellMisc/csv?build=1.60.1.70888
    https://wago.tools/db2/SpellClassOptions/csv?build=1.60.1.70888
    https://wago.tools/db2/SpellLevels/csv?build=1.60.1.70888
    Periodic schedules use the SpellMisc duration index and SpellDuration,
    with aura intervals from SpellEffect. Arcane Missiles uses the child
    effect coefficient for each triggered missile:
    https://wago.tools/db2/SpellDuration/csv?build=1.60.1.70888
    Bloodthirst uses the attack power percentage from its Spell description
    and matching SpellEffect base points. Arcane Shot and Serpent Sting coefficients come
    from Blizzard's November 2 Forever beta development notes:
    https://us.forums.blizzard.com/en/wow/t/wow-forever-beta-development-notes-%E2%80%93-updated-november-2/2360696
  - Blizzard's Forever UI API documentation, preserved by Gethe:
    https://github.com/Gethe/wow-ui-source/tree/4cd0ab752a77164f654ccbca9d0c1fe8dafceebe/Interface/AddOns/Blizzard_APIDocumentationGenerated
    Camelot's character sheet combines spell hit rating and spell hit
    modifier:
    https://github.com/Gethe/wow-ui-source/blob/4cd0ab752a77164f654ccbca9d0c1fe8dafceebe/Interface/AddOns/Blizzard_UIPanels_Game/Camelot/PaperDollFrameStats.lua
    Effective levels and armor/resistance API usage:
    https://github.com/Gethe/wow-ui-source/blob/4cd0ab752a77164f654ccbca9d0c1fe8dafceebe/Interface/AddOns/Blizzard_UnitFrame/Camelot/TargetFrame.lua
